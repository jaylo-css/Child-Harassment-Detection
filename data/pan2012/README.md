# PAN-2012 (optional, user-provided)

Place the PAN-2012 Sexual Predator Identification corpus files you obtained yourself from the PAN
organizers here (`*.xml` plus the predator ID `.txt` files). This directory is `.gitignore`d.

SafeChat Guardian never downloads, bundles or prints this corpus. Its loader
(`app/ingest/pan2012.py`) reports metrics only. The corpus contains explicit text, so do not open
or share it casually, and never paste it into issues, logs or prompts.
